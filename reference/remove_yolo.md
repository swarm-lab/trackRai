# Remove YOLO

This function automates the removal of YOLO and all its Python
dependencies from your system.

## Usage

``` r
remove_yolo()
```

## Value

Nothing.

## Note

The function will only remove the dedicated Python virtual environment
from your system. If Python was installed during the execution of
[`install_yolo()`](https://swarm-lab.github.io/trackRai/reference/install_yolo.md),
it will not be removed.
